# Production dependencies for the container image.
#
# Kept separate from requirements.txt on purpose: that file is the developer
# environment and carries the test tooling. This one is what ships, and every
# line it leaves out is image size a free-tier host does not have to hold.
#
# Two deliberate differences from the dev file:
#
#   * xgboost is pinned below 3.0. From 3.0 the wheel declares a hard
#     dependency on nvidia-nccl-cu12, which pulls 454 MB of CUDA runtime that
#     a CPU-only web service never loads. 2.x is the same algorithm without
#     the GPU baggage, and takes the image from ~1.1 GB to ~600 MB.
#   * pytest, httpx and pymoo are omitted. The first two are test-only;
#     pymoo is an optional hypervolume backend that benchmarking/metrics.py
#     already falls back from when it is absent.
